# Maven 4 Testing Framework Issues

## Problem
When trying to use Maven 4's @MojoTest annotation with @InjectMojo, we encounter XML parsing errors:

```
ParseError at [row,col]:[19,7]
Message: Unrecognised tag: 'requiresDirectInvocation'
```

## Root Cause
The Maven 4 testing framework's XML parser doesn't recognize the `requiresDirectInvocation` tag that's generated by maven-plugin-tools 3.11.0 in the plugin descriptor.

## Attempted Solutions
1. ✅ Added `maven-testing` dependency correctly
2. ✅ @MojoTest and @InjectMojo annotations are now available
3. ❌ Plugin descriptor compatibility issue prevents tests from running

## Current Status
- Maven 4 DI system is working in production code
- All components successfully converted to DI: PhaseAnalyzer, MavenExpressionResolver, PathResolver, GitIgnoreClassifier, NxTargetFactory, etc.
- Testing framework has compatibility issues with generated plugin descriptor

## Alternative Approaches
- Use reflection-based testing (previous working approach)
- Wait for Maven 4 testing framework improvements
- Create custom test harness for DI components

## Key Learning
Maven 4's DI system works well for production, but the testing framework is still evolving and has compatibility issues with plugin descriptor formats.
